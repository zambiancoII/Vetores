# 📈 Sistema de Controle de Vendas (Matrizes e Vetores Paralelos) em C++

Uma aplicação desenvolvida em **C++** para gestão e análise de desempenho de vendas, cruzando dados de uma matriz bidimensional (produtos versus vendedores) com vetores textuais para gerar relatórios consolidados de faturamento e produtividade.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte da **avaliação de Estrutura de Dados** solicitada pelo **Professor Cação**. O objetivo principal da atividade foi demonstrar o domínio prático na manipulação de **matrizes 3x4**, associação com **vetores unidimensionais de strings**, uso de laços de repetição aninhados e algoritmos de busca por valores máximos e somas direcionadas.

---

## ⚙️ Funcionalidades do Sistema

O programa processa uma matriz estática de vendas por item e por colaborador, executando as seguintes análises automáticas:

1. **Exibição da Matriz de Vendas:** Apresenta detalhadamente no terminal o quantitativo vendido de cada produto por cada vendedor.
2. **Total por Produto:** Calcula e exibe a soma geral de unidades comercializadas de cada item (Smartphones, Notebooks e Smartwatches).
3. **Total por Vendedor:** Soma e exibe o volume total de produtos vendidos individualmente por cada colaborador.
4. **Produto Mais Vendido:** Varre a matriz de forma acumulada para identificar e destacar qual foi o produto de maior saída geral.
5. **Vendedor Destaque:** Analisa o volume total de vendas por coluna para identificar e premiar o vendedor(a) com a maior quantidade total comercializada.
